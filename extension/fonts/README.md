# Bundled typography

DM Sans by the DM Sans Project Authors, obtained from the Google Fonts `ofl/dmsans` distribution:
https://github.com/google/fonts/tree/main/ofl/dmsans

`dm-sans-latin-variable.woff` is a local variable-font subset made with fontTools from `DMSans[opsz,wght].ttf`. It includes U+0000–024F, U+1E00–1EFF and U+2000–206F; other characters use the system sans-serif fallback. Variable weight and optical size tables are retained. No browser request to Google Fonts is needed. This is the only font binary shipped for the options page.
