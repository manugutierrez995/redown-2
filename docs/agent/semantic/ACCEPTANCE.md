# Repeatable cold-agent session

Run from a clean checkout with Node 24 or later. Basic inspection uses only Node built-ins and no network. `npm ci --cache /workspace/.npm-cache --no-audit --no-fund` is needed once for jsdom-based reproductions/tests; after dependencies are cached/installed the workflow runs offline. Node 24's `--test-isolation=none` is used to expose actual subtest counts; no browser claim follows from it.

1. Discover `node agent/semantic/cli.mjs describe --json`, then `listEntities --input '{"kind":"capability","limit":100}' --json`. Find `redown.upload.destination.selection` by purpose without a filename hint. `projectOverview` identifies frozen sibling APIs, pin and coverage; `getCoverage` paginates all public artifacts with semantic owners.
2. `describeEntity --input '{"id":"redown.upload.destination.selection","depth":2,"limit":100}' --json` resolves destination-fidelity intent, immediate-children, separate-draft and request-freshness invariants, located options DOM/state, actual background message interfaces and test entities.
3. `traceEvidence --input '{"id":"redown.incident.dbg-003","depth":1,"limit":100}' --json` retrieves exact original event IDs and later appended outcomes/provenance/digests. DBG-001 and DBG-002 remain separately navigable; adjacency is not proof of a shared cause. `traceDependencies` supports both directions and bounded depth.
4. `explainChangeImpact --input '{"changed":["redown.upload.destination.selection"],"limit":100}' --json` gives **possible** affected capabilities, edge rationales and regression targets. `planVerification` formulates stale-child-cache and provider-misclassification hypotheses, their falsification scope and candidate anchors. Root-request guarding is explicit counterevidence against a blanket unguarded-chooser hypothesis.
5. `node agent/semantic/workflow.mjs` is dry-run. In a permitted environment, `node agent/semantic/workflow.mjs --execute-local-tests` runs only the fixed Upload/Simple fixtures and records runtime/platform, command, time, count, exit result, output digest and proof scope. It cannot accept a shell command or deploy. The child-race reproducer executes the **current actual source slice** in an isolated VM with jsdom and mocked `cfFolderChildren`, not a duplicate implementation. Alpha/beta and child names are fixture data. Cancel via `AbortSignal` in the library; timeout/output limits terminate execution.
6. `exportLesson --input '{"id":"redown.lesson.request-context-freshness"}' --json` emits a decision proposal with a standard manifest/file map, traceable origins, evidence, counterevidence, applicability and limits. `validateForeverProposal` uses the actual vendored upstream reference API. `python tests/semantic-schema-conformance.py` independently checks actual published schemas. **Current result: reference library valid, published schemas invalid due to upstream version regex; compatibility blocked.** Draft upstream PR #5 is separate and unmerged.
7. Repeat `describeEntity` and `traceEvidence` for `redown.simple.menu.flat`. Its flat parentage, fallback implementation, tests, source/owner-contract conflict and DBG-002 are independently represented. The graph is not a hardcoded Upload answer.
8. `getCoverage` and `validateSemanticGraph` expose all finite public paths, strata and missing/stale evidence. Pagination is explicit; a new public file warns until inventoried/reviewed. Private stores/tokens and live R2 are gaps, not implicit access.

The actual structured transcript is [verification/acceptance-session.json](verification/acceptance-session.json); the [executed workflow](verification/workflow-result.json) and [lesson proposal](verification/lesson-proposal.json) are retained separately. Repeat inspection should be deterministic for unchanged source and graph; execution timestamps/durations are intentionally observations. Transcript is a source snapshot and may become stale after subsequent code edits.

`agent/semantic/observer.mjs` is a concrete opt-in DOM count observer. In the authorized options-page DevTools console, paste its exported function definition with the `export` keyword removed, then run:

```js
observeUploadDom(document, {scope:'observe-dom-counts', approved:true})
```

It returns row/option counts and disabled booleans only; never reads labels, option values, input contents, storage or network. It cannot prove bucket identity, draft emptiness or remote correctness. It adds no shipped extension permission or persistent hook. No observer run on installed Chrome was performed in this task. DOM unit tests verify consent and no private-value reads only.

Live worker/console/network/R2/IndexedDB adapters remain unavailable. A future adapter must require an independently granted scope, approved redaction/retention, cancellation and fixed protocol operations; preparation/deployment requires a distinct mutation scope.
